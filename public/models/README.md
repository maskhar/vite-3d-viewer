# 3D Models Directory

Place your `.glb` or `.gltf` 3D model files in this directory.

## Expected Files

Based on the catalog configuration in `src/data.ts`, the following model files are expected:

- astronaut.glb
- camera.glb
- vehicle.glb
- mechanical.glb
- architecture.glb
- sculpture.glb

## Note

If model files are not present, the viewer will display a wireframe placeholder cube. 
You can easily add your own models by placing them here and updating the catalog in `src/data.ts`.
