📊 TECHNICAL SPECS

Database:
   • Table: public.categories
   • Columns: id, name, description, display_order, is_active, timestamps
   • Indexes: display_order, is_active, name
   • RLS: Enabled dengan 5 policies

Functions:
   • create_category(name, description)
   • update_category(id, name, description)
   • delete_category(id)
   • toggle_category_status(id, is_active)

Component Stack:
   • React + TypeScript
   • @dnd-kit/core untuk drag & drop
   • Supabase client untuk database
   • Lucide React untuk icons
   • Tailwind CSS untuk styling
